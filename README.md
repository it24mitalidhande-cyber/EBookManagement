### GitHub Webhook Testing

This project uses GitHub Webhooks to automate the Jenkins CI/CD pipeline.

Whenever a developer pushes changes to the GitHub repository, GitHub sends a webhook notification to Jenkins. Jenkins automatically triggers the configured job to build and test the application.

**Purpose:** To verify automatic Jenkins job triggering after a GitHub commit.
